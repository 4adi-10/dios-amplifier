# Discord Amplifier

Boost your mic for Discord.

- **Web app** (`index.html`): amplify your mic up to 10000x and send it to a virtual cable (VB-Cable). Set your Discord input to "CABLE Output".
- **Chrome extension** (`extension/`): boosts your mic inside Discord Web. Load it from `chrome://extensions` with Developer mode on, using "Load unpacked".

Extreme gain clips into static. Use headphones to avoid feedback.
