Setup for the Discord app in three steps

The desktop app cannot be boosted directly, so the sound goes through VB-Cable, a free virtual audio cable.

  1. Install VB-Cable

    Download it from VB-Audio, run the installer as admin and restart your PC.

  2. Send DIOS to the cable

    In the amplifier, set Output to CABLE Input and press Start.

  3. Pick the cable in Discord

    In Voice and Video settings, set Input Device to CABLE Output and turn off automatic gain control.

Chrome extension for Discord in the browser

It boosts your mic inside discord.com with no cable. Same 100,000x gain, EQ and limiter, from a popup.

  1. Download the folder

    Get the extension folder from GitHub.

  2. Load it in Chrome

    Open chrome://extensions, turn on Developer mode, click Load unpacked.

  3. Rejoin voice

    Reload Discord and join the channel again.

Questions

How does 100,000x stay clear?

The Loud and clear limiter compresses your voice and holds every peak just under full scale, so it never clips into static.

Do the hotkeys work in other windows?

No. M, Space and R work while this tab is focused. Use Discord’s own keybinds for in-game push-to-talk.

Does it work on a phone?

Not in the Discord app. Phones block virtual cables and mic changes between apps.

Which browsers work?

Chrome and Edge on Windows or Mac. Firefox runs it, but cannot pick an output device.

Is my voice sent anywhere?

No. All the audio work runs in your browser, and nothing is uploaded.
